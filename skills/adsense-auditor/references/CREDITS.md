# Credits

The 73-item checklist structure and the audit-workflow shape are adapted from a public
"AdSense Site Auditor" skill template published by **CoworkHow** (`coworkhow`), an independent
resource that is not affiliated with Anthropic or Google. Original template editorial note:
"Written by Jason Guo. Reviewed by CoworkHow editorial review."

Changes made for this project (2026-09-09):

- All policy source URLs switched from `?hl=zh-Hans` (Chinese) to `?hl=en` (English), and a few
  stale links replaced with the current English Google pages (Publisher Policies and Publisher
  Restrictions now live under `support.google.com/publisherpolicies/`).
- Added English source URLs for ads.txt setup, ad-placement policy, invalid traffic,
  personalized-advertising restricted data, the EU user consent policy, Google-certified CMP
  minimum functionality, and COPPA / child-directed treatment.
- Added an explicit ID index for the completeness gate.
- Output format tightened to include a `Severity` column and the standing line that the audit is
  an assessment, not a guarantee of approval.

**Authority:** all policy content is re-grounded in Google's own English documentation. Where the
live Google doc differs from this file, the live doc is authoritative.
